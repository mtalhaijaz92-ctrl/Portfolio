Why every table needs a primary keySQL & databases

A primary key gives each row one unique, never-empty identity. Without it you can’t safely update or delete a single record, and foreign keys in other tables have nothing to point to. In my student database, student_id links a student to their fee records.

CREATE TABLE students (
  student_id INT PRIMARY KEY,
  name VARCHAR(60) NOT NULL
);
Three Python habits that made my code cleanerPython tips & tutorials

Use f-strings instead of string concatenation, loop with enumerate() when you need the index, and wrap risky file work in try/except so one bad input doesn’t crash the program.

for i, name in enumerate(["Ali", "Sara"], start=1):
    print(f"{i}. {name}")
# 1. Ali
# 2. Sara

AI agents in simple wordsAI / GenAI basics

A language model answers questions. An AI agent goes one step further: it can decide what to do, call tools such as a search or a database, look at the result and continue until the task is done. Python basics like functions, loops and lists are exactly what you need to build one.
